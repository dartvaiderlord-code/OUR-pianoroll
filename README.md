# OUR-pianoroll

Нативный MIDI-визуализатор для Android и Windows с неоновым пиано-роллом. Приложения используют Godot и работают офлайн. В репозитории также есть самостоятельная HTML-версия.

## Скачать

- **Android** — APK для ARM64 и x86-64, Android 7.0 и новее.
- **Windows** — ZIP с переносимым EXE для x64.
- **Браузер** — файл `our-pianoroll.html`, который можно открыть локально.

[Готовые сборки и HTML](https://github.com/dartvaiderlord-code/OUR-pianoroll/releases/latest)

## Возможности

Одновременное воспроизведение до 16 MIDI-файлов с отдельными цветами и раскраской нот внутри каждого файла. Ноты верхних MIDI-слоёв в списке перекрывают нижние. Есть демо, перемотка, повтор, регулировка скорости и громкости. На клавишах можно играть мышью и касаниями.

Интерфейс доступен на русском и английском. Можно менять тему, стиль клавиш, фон, цвет и форму нот, подсветку, частицы, лучи, вспышки и направляющие. Пользовательские изображения остаются на устройстве.

В разделе **Клавиши и фон** режим **Свой диапазон** позволяет выбрать первую и последнюю ноты или задать от 1 до 128 клавиш. Падающие ноты занимают ширину соответствующих клавиш. Фоновое изображение заполняет водопад нот с сохранением пропорций. Если пропорции различаются, изображение центрируется, а лишнее уходит за края кадра.

Кнопки **Добавить MIDI** и **Демо** находятся в панели **Настройки**. В Android интерфейс прокручивается вертикальным свайпом. Касания клавиатуры продолжают играть ноты. В разделе **Визуальные эффекты** можно выбрать рисунок эффекта нажатия, задать его размер от 25 до 300% и отдельно включить световые столбы.

## Видео

Кнопка **Видео** открывает параметры разрешения, FPS и качества. В режиме **Покадровый экспорт** задайте начало и конец фрагмента MIDI. В режиме **Живая запись** можно управлять воспроизведением и играть на клавишах, а затем нажать **Стоп**. Экспорт использует выбранные эффекты и масштабирует их пропорционально высоте ролика.

Нативное приложение сохраняет MKV с видео MJPEG и аудио PCM. Кадры рассчитываются по указанному FPS независимо от частоты монитора. Для FPS можно ввести 120, 144, 240 или другое значение. Разрешение и качество влияют на время обработки и размер файла. Видео можно открыть в VLC или другом проигрывателе с поддержкой MJPEG в MKV.

## Исходники и сборка

- `native/` — проект Godot 4.6.3 с пресетами Windows и Android.
- `web/index.html` — готовый автономный HTML.
- `web/src/` — исходники HTML-версии. Команда `bash web/build.sh` обновляет HTML и его копию внутри нативного приложения.

Установите Godot 4.6.3 и его шаблоны экспорта. Для Android укажите путь к Android SDK и OpenJDK в настройках редактора. Используются Android SDK Platform 36, Build Tools 36.0.0 и Platform Tools.

```sh
mkdir -p build
godot --headless --path native --editor --import
godot --headless --path native --export-release Windows "$PWD/build/our-pianoroll.exe"
godot --headless --path native --export-release Android "$PWD/build/our-pianoroll.apk"
```

Файл `native/assets/sound-bank.bin` содержит готовые сэмплы синтезатора. После изменения тембров его можно пересобрать командой `godot --headless --path native --script res://tools/build_sound_bank.gd`.

Для подписи APK в Godot задайте `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `GODOT_ANDROID_KEYSTORE_RELEASE_USER` и `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD`. APK первого релиза подписан ключом разработки. Для последующего обновления поверх установленного APK нужен тот же ключ.

Проверка движка и интеграции

```sh
godot --headless --path native --script res://tests/integration.gd
godot --path native --script res://tests/integration.gd -- --video
```

Проверка с `--video` требует графического сеанса. Она создаёт тесты Full HD при 144 FPS и живой записи при 120 FPS в каталоге данных приложения. Лицензии и уведомления Godot и его зависимостей находятся в [native/assets](native/assets).
